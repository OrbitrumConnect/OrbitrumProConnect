### Backend local iniciado
- **Problema:** todos os endpoints /api/* retornavam 500 no frontend (localhost:3000).
- **Causa:** o backend (pasta `backend/`, Express na porta 5000) nao estava rodando.
  O Vite faz proxy de `/api/*` para `http://localhost:5000`. Sem backend = 500.
- **Solucao:**
  1. `npm install --legacy-peer-deps` no root (node_modules nao existia)
  2. Adicionado `paths: { "@shared/*": ["./shared/*"] }` no `backend/tsconfig.json`
     (o tsx nao resolvia o alias sem isso — no PC do Pedro provavelmente resolvia por
     versao diferente de Node/tsx)
  3. Criado `backend/.env` com SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY,
     GOOGLE_CLIENT_ID, SESSION_SECRET (sem DATABASE_URL — roda com MemStorage fallback)
  4. Backend subiu: `npx tsx index.ts` na pasta backend → porta 5000, endpoints respondendo
- **Nota:** sem DATABASE_URL, o backend usa MemStorage (dados demo em memoria).
  Para dados reais do Supabase, precisa da DATABASE_URL (pooler, porta 6543, com senha).
